# 看股工作台（DSH 插件）

左侧栏一个「看股」图标 → 点击进入整页工作台：全 A 股当日快照、多指标排序、条件选股。

- 数据源：东方财富公开行情接口（Host 侧 Node 抓取，浏览器不直连行情站）
- 股票池：全 A 5927 个代码，其中约 5572 只可交易（355 条退市/停牌占位自动过滤）
- 刷新：手动（点一次拉一次），Host 侧 3 秒内缓存复用；收盘后缓存放宽到 5 分钟

## 数据口径与已知限制

- `f11` 是 **5 分钟**涨跌幅，`f109` 才是 5 日涨跌幅；本插件只展示 5 日。
- 主力净流入 `f62` 东财对全市场约 15% 的股票恒返回 0（北交所居多）→ 显示为 `—`，排序时按"无数据"排在最后，不参与 `≥ N 万` 筛选。
- 涨跌家数用**自建快照统计**（与榜单同口径）；涨停/跌停家数用东财专题池（ST 5%、创业/科创 20%、北交 30%、新股不限，阈值法会算错）。
- 退市/停牌占位条目（`f2 === "-"`）在 Host 侧过滤，不进榜单。
- 涨跌色沿用 A 股习惯：红涨绿跌。
- **防御指标口径**（重要，指标已并入全 A 榜单列，红利策略已并入公式收藏夹）：
  - `股息率 = 近 12 个月已实施的税前每股派息 / 现价`，数据来自东财数据中心「分红送配」，缓存 6 小时；**不是**分红率，也不含未实施的分配预案
  - `分红年数 = 近 3 年里有分红的报告年度数（0~4）`；`连续分红 = 从最新报告年度往回逐年连续的年数（上限 10，显示 10+）`，窗口 10 年，故 10+ 表示"至少 10 年"而非精确值
  - 分红明细来自东财「分红送配」的**已实施**记录（不含未实施方案）；首次抓取约 36k 条 / 5.6s，之后落盘快照 `state/dividend-cache.json`，重启秒开、过期后台刷新
  - `ROE / 负债率 / 毛利率 / EPS` 取**最近一期报告、未年化**；银行负债率天然 90%+，不要用「负债率 < 60」筛银行
  - 一次性特别分红会把股息率顶得很高（例如某些公司 15%+），要结合 `分红年数` 与盈利稳定性看，别只看股息率排名
- 自选池与自动刷新间隔存在 `localStorage`（键：`dsh-stock-workbench:watchlist` / `dsh-stock-workbench:auto-seconds` / `dsh-stock-workbench:formulas`），换浏览器/清缓存会丢，但不影响行情数据。
- **预置公式是近似，不是原版策略**：CANSLIM 的 C/A（季度盈利、营收增速）、I（机构持仓），唐奇安通道的 20 日 K 线序列，RSI 指标序列都不在快照字段里。每条预置的 `note` 写明了缺什么、怎么替代。K 线类条件（20 日新高 / 均线金叉 / MACD 金叉）请用「信号扫描」tab。

### 公式写法（容忍日常书写习惯）

| 都能写 | 归一化后等价于 |
|---|---|
| `[量比] > 2`、`` `量比` > 2 ``、`**量比** > 2` | 方括号/反引号/星号被忽略 |
| `量比＞２`、`涨跌幅≥３`、`量比≠４` | 全角符号、全角数字自动转半角；`≥ ≤ ≠` 直接支持 |
| `涨跌幅 between 0~1`、`between 0 到 1` | `~`、`到`、`至` 等价于 `and` |
| `量比>2 && 涨跌幅>0`、`量比>2 || 涨跌幅>0` | `&&` → 且，`||` → 或 |
| `量比>2，涨跌幅>0` | 全角/半角逗号、分号都当「且」 |
| `（量比 > 2 或 涨跌幅 > 0）且 换手率 > 1` | 全角括号 |
| `名称 contains "银行，保险"` | 字符串里的内容**原样保留**，不会被转成半角 |

报错位置始终指向**原文**下标（归一化是 1:1 替换，不改变长度）。

### 为什么信号扫描是「两段式」

全市场 5572 只逐个拉日 K = 5572 个请求，不可行。所以先用**已有快照**粗筛候选池（成交额门槛、排除 ST、按成交额取前 N），只对候选池拉日 K（默认 150 只 × 180 根，6 并发，实测 ~1s）再算信号。命中率低的时候把成交额门槛调低、候选上限调大即可。

单次刷新 = 1 次全集（仅进程启动后首次，60 页并发 6）+ 8 批 `ulist` 快照（800 只/批，并发 4）+ 1 次指数 + 1 次家数 + 2 次涨跌停池；实测 700ms–1.4s，响应 1.23MB（14 字段/行）。

## 开发说明

- Host 侧改动：重启 DSH 或重装 bundle（loader 层变化不走热更）。
- Client 侧改动：`client.js` 属于打包后的 client 资源，**改完需要重新安装/刷新页面**；只有 `pnpm run dev:web` 在跑时才有 HMR，本机未跑。
- Client 半端不依赖任何 Harness Client 包（不 require `ui-primitives`），样式只用 `--dsw-alias-*` 主题 token，主题切换自动跟随。
