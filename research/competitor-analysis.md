# 看股工具竞品调研与功能对比

> 调研时间：2026-11-04 ｜ 对比对象：DSH「看股工作台」插件 vs 市面主流看盘/选股/数据工具
> 说明见文末「调研方法与可达性」，未在线核实的部分已标注「据公开认知」。

## 1. 竞品地图（四类）

| 类别 | 代表产品 | 定位 |

| **A. 专业终端**（付费，券商/机构为主） | 同花顺 iFinD、Wind、东方财富 Choice、通达信研究终端、大智慧 | 全量数据 + 深度财务/宏观 + Excel/API 取数；功能极全，学习成本与价格高 |

## 3. 本插件的能力基线（如实）

- 数据：全 A **5574 只**，19 项快照字段 + 10 项防御字段（股息率/分红年数/连续分红/PB/PE/ROE/负债率/毛利率等）
- 表格：**20 列**、虚拟滚动、点表头排序、列配置（每 tab 独立、显示/固定/拖拽排序、持久化）
- 详情：6 周期 K 线（补历史到 2400 根）+ 当日分时 + 4 指标 + 缩放/平移/滑条
- 信号：6 信号 × 4 周期 × 3 窗口，两段式扫描（快照粗筛 → 候选池拉 K）
- 公式：26 字段、容错解析（全角/方括号/between/contains/&&）、可视化构造器、15 条预置与收藏夹
- 红利：10 年分红明细、连续分红年数、股息率
- 其他：自选、自动刷新、CSV 导出、9 条本地 HTTP 路由

## 4. 关键差异（我们明显强 / 明显弱）

**强于多数免费工具的地方**
1. **分红深度**：逐笔明细（报告期/除息日/每10股/每股/方案）+ 连续分红年数，免费工具通常只给股息率一个数
2. **公式可编程**：不是固定几个模板，而是可写条件 + 收藏复用 + 导入导出；多数免费工具的"条件选股"字段固定、不可保存自定义
3. **列配置 + 排序 + 本地持久化**：行情网站表格通常不能自定义列与固定
4. **零依赖本地**：不用账号、不连第三方云，数据直连公开接口；断网仅影响刷新
5. **两段式信号扫描**：先快照粗筛再拉 K，5560 只全市场扫描不炸接口

**明显弱于主流工具**
1. **无实时推送**（轮询而非长连接；Level-1 也有延迟）
2. **无板块/概念归属**，无法做"板块资金流/概念筛选"
3. **无龙虎榜/融资融券/大宗/机构调研/股东**等筹码类数据
4. **无估值分位**（PE/PB 历史百分位），价值选股的关键判据缺失
5. **无提醒/预警**（价格、信号、公告）
6. **无社区/研报/题材**（雪球、韭研、东财股吧的护城河）
7. **无多市场**（港美、可转债、ETF、REITs；集思录维度）
8. **无回测**（策略只能"当下选出来"，不能验证历史表现）

## 5. 建议的下一步（按性价比排序）

**P0（数据已有、成本低、收益直观）**
1. **板块/概念归属 + 板块资金流**：东财有现成板块接口；给榜单加「板块」列 + 板块 TOP 资金流子页
2. **自选分组**：多组自选（红利组/短线组），复用现成列配置与持久化机制
3. **价格/信号提醒**：前端定时检查 + 浏览器通知/页内提示（无需后端）

**P1（一次抓取即可长期用）**
4. **估值分位**：拉 PE/PB 历史序列算百分位（东财 K 线/财务接口可拼），做成「估值」子页或榜单列
5. **财务三表关键项**：营收/净利/现金流/应收/存货周转，扩充快照字段与公式字段
6. **龙虎榜 + 融资融券**：东财数据中心有，做成「筹码」子页
7. **简单回测**：用日线 + 公式条件做「历史某日命中 → 之后 N 日收益分布」，轻量版即可

**P2（有取舍）**
8. **一句话选股**（问财式：把「最近三天主力净流入超 5000 万且换手率大于 5%」转成公式）——注意：是"翻译成公式"而不是聊天，符合之前去掉 AI 侧栏的取向
9. **多市场**（先港股基础行情）——数据源与代码兼容成本较高
10. **画线工具**——交互复杂度高于数据成本

**不建议做**：Level-2/实时推送、交易通道、社区/研报库。前两者有授权与合规成本，后者是内容运营而非工程问题，个人维护不现实。

## 6. 结论

- 对标 **东财条件选股 / 问财 / 理杏仁筛选** 这一层（"选股 + 看盘"，不是全功能终端）
- 差异化定位：**本地、免费、可编程、可自定义表格与列、分红维度做得比免费工具深**
- 不追求替代同花顺/Wind：功能矩阵里 A 类的护城河是数据授权与内容生态，不是单个页面能做出来的

## 7. 调研方法与可达性（诚实说明）

- `web_search`：**不可用**（无 DeepSeek API key）
- 直接抓取成功：东方财富数据中心（功能目录）、集思录（数据站功能）、韭研公社（题材/纪要/复盘）、通达信官网（产品线/AI 平台）、理杏仁（筛选/可视化/开放平台）
- 抓取失败：TradingView（网络拦截）、雪球（跨域跳转）、DuckDuckGo/Bing（拦截）、同花顺问财（SPA，只拿到标题）
- 因此：**A 类专业终端与 D 类海外的具体功能项，部分依据公开产品认知，非当日页面核实**；价格与功能可能变化
- 本插件能力项均来自实际代码与当日接口实测（可复现：`STATUS.md` 的自测命令）
